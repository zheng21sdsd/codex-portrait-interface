# Support

Use GitHub Discussions for usage questions and feature ideas. Use issues for reproducible bugs after reading [troubleshooting](docs/troubleshooting.md).

Before opening an issue, run the read-only `doctor` command and include only the non-sensitive result:

```powershell
node .\skills\codex-portrait-interface\scripts\codex-layout-copy.mjs doctor --json
```

Do not post private images, conversations, user profiles, application archives, logs, `manifest.json`, secrets, or absolute local paths. For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
